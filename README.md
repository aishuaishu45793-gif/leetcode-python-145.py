## 📝 Program Details

### 141. Check Whether a Number Is Prime

**Objective:** Determine whether a number is prime.

A prime number is greater than 1 and has exactly two positive factors: 1 and itself.

**Concepts Used:**

* Variables
* Conditional statements
* `for` loops
* Modulo operator (`%`)
* Mathematical operations

**Example Output:**

```text
Enter a number: 7
Prime number
```

**Time Complexity:** O(√n)

### 142. Reverse a String

**Objective:** Reverse a string entered by the user.

**Concepts Used:**

* Strings
* Variables
* User input
* String slicing

**Example Output:**

```text
Enter a string: Python
Original string: Python
Reversed string: nohtyP
```

**Time Complexity:** O(n)

### 143. Sum of Digits

**Objective:** Calculate the sum of all digits in a non-negative integer.

**Concepts Used:**

* Strings
* Loops
* Integer conversion
* Arithmetic operations
* Input validation

**Example Output:**

```text
Enter a non-negative integer: 1234
Sum of digits: 10
```

**Explanation:** 1 + 2 + 3 + 4 = 10.

**Time Complexity:** O(n), where n is the number of digits.

### 144. Count Words in a String

**Objective:** Count the words in a sentence entered by the user.

**Concepts Used:**

* Strings
* `split()`
* `len()`
* User input

**Example Output:**

```text
Enter a sentence: Python is easy to learn
Number of words: 5
```

**Time Complexity:** O(n), where n is the length of the sentence.

### 145. Find Common Elements in Two Lists

**Objective:** Find the distinct numbers that appear in both lists while preserving their order in the first list.

**Concepts Used:**

* Lists
* Loops
* Conditional statements
* Membership checking using `in`
* Duplicate prevention

**Example Output:**

```text
Enter the first list: 1 2 3 4 5
Enter the second list: 3 4 5 6 7
Common elements: [3, 4, 5]
```

**Explanation:** The numbers 3, 4, and 5 appear in both lists.

**Time Complexity:** O(n × m) in the worst case for the basic list-membership implementation, where n and m are the lengths of the two lists.

## ⚙️ How to Run the Programs

### Prerequisites

* Install Python 3.
* Install Visual Studio Code.
* Ensure Python is available from your terminal.

2. Open the project folder in VS Code.

4. Run the Python file you want to practice.

